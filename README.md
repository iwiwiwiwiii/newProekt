# Интернет-магазин животных

## Описание
Веб-приложение для продажи домашних животных. Разработано на React.

## Функционал
- Регистрация пользователя
- Каталог товаров с карточками
- Фильтрация по категориям (птицы / животные)
- Поиск по названию
- Детальная страница товара
- Корзина (добавление, удаление, изменение количества)
- Оформление заказа
- Адаптивный дизайн

## Технологии
- React 18
- React Router DOM
- Context API
- Vite
- CSS3 / Flexbox
- LocalStorage
